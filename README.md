# Python Projects

A small collection of standalone desktop apps built while learning Python.
Each file is self-contained and can be run directly.

## Apps

### `calculator.py`
A basic calculator with a `tkinter` GUI supporting standard arithmetic
operations.

Run:
```
python calculator.py
```

### `paint.py`
A simple paint/drawing program built with `tkinter`, supporting tools like
pencil, shapes, and color selection, plus opening/saving images.

Run:
```
python paint.py
```

### `snake-game.py`
A classic Snake game built with `pygame`, featuring selectable difficulty
levels, sound effects, and persisted high scores (saved to
`snake_high_scores.json`).

Run:
```
python snake-game.py
```

## Requirements

- Python 3
- `tkinter` (included with most standard Python installs; used by
  `calculator.py` and `paint.py`)
- `pygame` (used by `snake-game.py`; install via `pip install -r requirements.txt`)
